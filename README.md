This is a tool that lets users search English words and get Siswati translations of them with pronunciation guides. It is the first step to having an online library for African languages (particularly, the 11 official South African languages). It also serves to highlight both the differences(showcasing diversity) and similarities(showcasing a united people) between African languages in hopes for a better understanding among a people and a connection with one's roots. This project hopes to invite collaboration from people of other tongues to build a metaphorical, virtual bridge between people from different walks of life.
